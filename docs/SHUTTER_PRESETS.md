这是网页初始预设需求，不是已经实现的数据库。数值是普通镜头板安装通孔参考，不是螺纹大径、镜片组螺纹或攻丝底孔。用户可自定义，并应实测配合件。

## 2. 来源差异，不静默合并

同一家加工方的 [镜头板安装页](https://skgrimes.com/lens-board-mountings/) 列有 Copal #0 34.7、#1 41.8、Compur #00 26.6 mm，略不同于快门尺寸页。两页并未完整解释这些差异，不能直接断言全是统一公差。

产品默认采用上表快门页参考值，另展示“加工资料存在不同推荐孔径，请实测 / 自定义”的提示。不要求平均，不把差值藏进补偿，也不宣称 34.6 / 41.6 对任何材料、打印机和历史快门都恰好配合。当前孔径的制造补偿默认为 0。

用户新增明确选项：“3D 打印优化”，默认关闭，开启后在名义通孔直径上增加正值，默认 0.5 mm（直径增量）。#0 实际 35.1、#1 实际 42.1、#3 实际 65.5 mm。标准数据不变；选预设不累计补偿；关闭恢复名义值；螺纹模式不自动施加此补偿。该值是用户指定的打印默认，不是快门厂家标准或通用制造保证。

Ilex、Compound、其他老式或特殊快门暂不提供通用编号映射，避免把不同品牌相同编号当成同孔径。可以使用自定义。

## 3. M 型螺纹输入不是快门通孔预设

选择“普通通孔”：显示通孔直径、X/Y 和快门预设。选择“M 型内螺纹”：显示公称外径 D、螺距 P，及高级有效长度 / 旋向 / 入口面 / 配合补偿。

例如 S.K. Grimes 快门资料中 Copal #3 通孔为 65.0 mm，安装螺纹为 M62×0.75。不能选择 #3 通孔后自动生成 M65 螺纹，也不能把镜片组前 / 后螺纹用作镜头板安装螺纹。网页首版不根据快门编号自动填写 M 螺纹，实际参数由用户确认。

“缠距”在界面统一写作“螺距 / pitch”。首版单线时导程等于螺距，默认右旋，M65×1 可作为自定义演示，不是 Copal #3 安装规格。

M 牙型目标参考 [ISO 68-1 基本与设计牙型范围](https://www.iso.org/standard/85107.html) 和 [Bossard 公制 ISO 螺纹尺寸说明](https://www.bossard.com/-/media/bossard-group/website/documents/technical-resources/en/f-079-en.pdf)：60°、明确名义大径 / 中径 / 小径关系。当前尚未实现或验证符合标准，不能宣称 ISO 公差等级合格。标准原文 / 图纸不复制到项目。

## 4. 数据与界面验收

- 后续预设记录包含 ID、品牌、型号、clearanceHoleDiameterMm、primarySourceUrl、secondarySourceUrls、checkedAt 和本地化警告。
- 原数值与实际 diameterMm 分开保存；手改显示“自定义”，JSON 保留参考预设 ID。
- 选择预设只修改当前普通通孔直径，不修改厚度、孔位、沉头或螺纹参数，不自动增加安装孔 / 防转销孔。
- 模式切换保持两个独立参数集合；首次切换螺纹必须确认 D/P，未确认不允许导出。
- 预设直径超出模板可加工区，保留用户选值并给出错误，不能自动换成较小型号。
- 中英文均显示单位、来源和关键警告；所有几何值与 ID 不因翻译而改变。
