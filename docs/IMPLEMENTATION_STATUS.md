# v0.1.0 实施与验证状态

日期：2026-09-14 · 实验性 alpha · 本轮已授权首次推送及 Pages 部署，正在发布；未做实物验收。最终部署证据将补充。

## 已实现

纯静态 React / TypeScript / Vite 网页，Three.js 预览，Replicad 1.1.0 / replicad-opencascadejs 1.1.0 单线程 WASM Worker。六个 STEP 直接内置白名单导入并核对 SHA-256；当地材料探针检查加工轮廓，Horseman 完整版保留两个实体。运行时坐标变换、厚度与保守圆区见 [模板目录](TEMPLATE_CATALOG.md)。

普通中央通孔、快门预设、自定义及偏心；可选打印直径正公差（默认关闭 / 存储 +0.5 mm）；M 基本 60°截形的真实内螺纹及明确的攻丝底孔模式；独立通孔、平底盲孔、锥形沉头、圆柱沉孔、正反面、圆周阵列、减薄座；两级法兰和扳手槽。

首次中文 / 英文切换、3D 视图、2D 孔位图点选中央孔、精确数字输入、撤销 / 重做、本地保存、受校验 JSON、分档 STL、STEP/STL ZIP。ZIP 包含参数 / 原 STEP / GPL / 来源。异常、过期或未经确认的实体不能导出；60 秒超时可重试重建内核。异步 revision 使用完整参数 JSON，不依赖文件名短 hash。

已增加亮色 / 暗色主题，首次跟随系统并记忆手动选择；主题与语言均不触发 CAD 重建。顶栏 Report 安全新标签页打开 RayforLoy/LensboardGenerator 的 Issues，不自动上传项目或创建 Issue。已提供锁文件、CI 检查和 main 推送自动 / 手动 Pages 工作流；远端为已有公开仓库。

生成证据位于被忽略的 tmp/cad-check/ 与 test-results/，运行 README 命令可重建；没有把生成模型混入源模板。六个原 STEP 的 SHA-256 全部未变；六个非 STEP 原文件均被 Git 忽略，dist/assets 中恰有六个 STEP，无私有 STL / SLDPRT / 本地路径。20 圈几何 / 重读通过，不代表已完成 30 秒导出性能目标或峰值内存验收。

检查中发现并修正两个实际问题：Horseman 附属体 STL 的一个浮点退化三角（只移除零面积面，并拒绝其他非流形输出）；OCCT 多圈螺纹刀具跨圆柱接缝会误分类（同一牙型刀具分为两个角向半体依次切除）。有体积切除下限检测，不以光孔冒充真实螺纹。通过样例不是任意输入皆成功的保证。

构建提示仍有 CAD 包受 Node 环境分支影响的 node:module externalization，以及约 805 kB 主 JS chunk 的体积警告；已通过实际浏览器初始化，不隐藏警告。单线程 WASM 约 22.98 MB（gzip 7.27 MB），首次加载与内存峰值优化尚待专项检查。

## 尚未完成 / 不宣称 PRD 全部验收

- 相机装机、卡口尺寸 / 光轴偏置实测、遮光、承重及打印螺纹试配；所有模板保持 experimental，不宣称 fitTested 或 6H 制造公差等级。
- 配对镜头板 / 法兰装配、专用试配件生成、背面螺纹入口选择（当前从当地正面向内定义长度）。
- 圆柱沉孔目前为通底孔，未提供盲底孔复合选项；自由多个 M 螺纹孔暂未实现，M 内螺纹限中央孔。
- 选中孔的 3D 高亮、真实模板外轮廓 / 剖面尺寸叠加、键盘点选二维孔位及逐字段错误关联尚不完整。二维图是孔位 / 加工区示意，不是制造图纸。
- 保守圆加工区 + 实体材料探针不是完整卡口保护实体建模；可能拒绝本可加工的筋位 / 大孔。不自动修改原模板、缩孔或忽略错误。
- 任意螺距 / 极限牙数 / 多特征排列的覆盖、强制模拟 WASM 下载错误 / 导出竞态 / 内存压力、浏览器 Firefox / Safari 及离线支持尚未验收。
- GitHub Actions Linux 环境、真实 Pages 部署和正式对应源分发方式还需远端确认；本地子路径通过不等于已发布。

P1 / P2（用户模板上传、矩形阵列、刻字、外螺纹、DXF、3MF 等）仍按 PRD 延后。第一版可用于本地设计与导出试验，不是经过制造认证的完整 P0 发布版。
