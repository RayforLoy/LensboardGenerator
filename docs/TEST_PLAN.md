# 验证与测试计划

状态：完整验收计划；v0.1.0 已执行的自动检查见 [实施状态](IMPLEMENTATION_STATUS.md)，本计划并非全部已通过。需求验收编号见 [PRD](../PRD.md)。每次报告必须区分自动通过、人工通过、待执行和失败。

## 1. 测试层次

| 层次 | 内容 | 证据 |
| --- | --- | --- |
| 参数单元测试 | schema、边界、PCD、角度、沉头公式、补偿和 JSON | 精确输入 / 期望值，不依赖截图 |
| 几何集成测试 | 模板、布尔、当地厚度、真实螺纹、实体有效性 | 参数、版本、体积、包围盒、有效性结果 |
| 独立导出重读 | STEP 实体与螺纹；STL 流形 / 法向 / 尺寸 | FreeCAD 或其他独立 CAD / 网格工具记录 |
| UI / 浏览器测试 | 双语、表单、点选、撤销、保存、异步与下载 | 实际浏览器版本、断言、失败截图 |
| 部署检查 | Pages 子路径、Worker、WASM、资产许可排除 | 部署 URL、网络响应、初始化和导出结果 |
| 实物检查 | 板体安装、卡口、遮光、螺纹试配、重镜头支撑 | 样机、材料、加工参数、测量与照片记录 |

FreeCAD 是独立验证候选，不是生产网页后端。未安装独立工具或未做实物检查时，必须报告未验证，不用同一写出内核自读替代独立证据。

- 打印优化：默认关闭 / storedAllowance=0.5；开启 #0→35.1、#3→65.5；切换预设不累计补偿；关闭恢复名义直径；零 / 负 / 非有限增加量在开启时拒绝；切换 M 螺纹不改公称径或螺距，JSON 往返一致。扩孔后的保护区与实体尺寸回归必须验证。
- 从 Copal #3 通孔 65.0 切换 M 螺纹不能自动生成 M65；要求公称外径 / 螺距确认，再用独立示例 M62×0.75 检查。切回通孔恢复原值。

- 原创测试板：100 × 100 × 5 mm，无筋位无圆角；中心孔 d=20 的期望体积为 `50000 - π × 10² × 5` mm³，误差 ≤0.1%。这不是相机模板标准。
- 偏心孔：d=10，x=15、y=-10；移到边缘越界时阻断或按 PRD 分类，不静默裁剪。
- 圆周孔：PCD=90、n=4、θ=0 时验证 PRD 坐标；θ=45 和偏移阵列中心验证三角函数 / degree 转换。n=0 不生成孔，非整数和负数拒绝。
- 沉头：d=3.2、D=6.2、α=90° → h=1.5 mm。测试 D≤d、角度 0 / 180、当地厚度不足和加工反面。组合特征不要误报自相交。
- 圆柱沉孔：底孔 d=3.2、沉孔 D=6.2、深度=2；分别验证通底孔、盲底孔、正反面与超深。
- 盲孔：厚 5、深 3；剩余 2 mm。超深和打在非均匀筋位上不能使用包围盒厚度判定。
- 局部法兰座：剩余厚度 2 mm；验证切除深度、孔位偏移、保护区和与其他孔交叠。
- 制造补偿：d=10、直径增加 0.2 → 实际 d=10.2；径向间隙不能直接当直径增加量使用。
- 法兰：外径 100、台阶外径 70、底厚 3、台阶高 2、内螺纹手动 M65 × 1、6 孔 PCD90、4 槽。仅演示数据；验证槽与孔的冲突、可关闭台阶 / 槽、薄壁失败。
- 真实螺纹：右旋 / 左旋、1 圈 / 20 圈、入口正面 / 背面、不同公称径和有效长度；检查螺旋方向、实际牙型、连通实体及 STEP 中的牙型保留。
- M 基本牙型：60°夹角、牙顶 / 牙底截形、大径 / 中径 / 小径与螺距关系；不能以存在螺旋切槽代替牙型检查，测试通过也不等于制造公差等级认证。
- 底孔模式：检查实际输出无牙、底孔用户确认直径、文件名与 JSON 标识；不得通过螺纹外观简化测试冒充真实几何。

## 3. 输出质量

STEP：独立打开为有效实体，无丢失面或意外碎片；与源实体比较体积误差 ≤0.1%、包围盒差 ≤0.01 mm。另对孔径、沉孔深度和螺纹剖面人工 / 工具测量，包围盒一致不等于内部特征正确。

STL：每条边正确连接两面，法向一致，封闭且无意外独立碎片；标准档关键尺寸误差 ≤0.05 mm。检查配置质量档确实改变细分 / 误差，不只改变文件名。复杂螺纹需要单独评估牙顶 / 牙底误差。

两零件分别测试，不允许依靠合并包围盒掩盖一个零件缺失。输出坐标不含组合预览移动。参数清单与实际输出模式、补偿和模板版本一致。

## 4. 交互与错误流程

- 深浅主题首次固定暗色（旧 v0.1.0 为跟随系统），切换 / 刷新保留；切换主题、语言及边线不增加 CAD build 请求且参数 JSON 不变。深蓝表单、二维孔图、警告、导出与手机顶栏有截图和溢出检查。Report 的目标为本仓库 Issues，含安全的新标签页属性，不自动创建或传输 Issue。
- 首次访问中文，切换英文、刷新保留英文；切换前后项目 JSON 的几何内容一致。
- 语言键完整、中文 / 英文错误和无障碍标签正确；数字点号解析清晰。
- 连续输入 A→B→C，只展示 C；模拟旧结果晚到、旧错误晚到、导出期间更改参数。
- 计算中、错误和过期状态禁用当前模型下载；重试 / Worker 重启后正常恢复。
- 模拟 WASM 下载失败、初始化失败、布尔失败、STEP 写出失败、网格失败和超时；只有仍有效的当前实体才可能提供 STL 替代。
- JSON 往返、未知 schema、未知模板版本、损坏数值、过大文件、重复 ID；失败后当前设计不变。
- localStorage 被禁止或容量不足仍可编辑和下载 JSON；恢复 / 重置有确认。
- 键盘操作、窄屏、深度 / 背面显示、坐标输入与二维点选一致。
- 上限 100 特征 / 40 圈及超限提示；不应静默丢孔、截螺纹或导出旧结果。

## 5. 部署与隐私

实际 Pages 子路径检查首页刷新、静态模板、Worker 入口、WASM locateFile、初始化、导出和语言存储。不只测试 localhost 根路径。

网络检查不包含模型 / 参数上传或任意外部脚本执行。构建产物和源码分别检查 `scadtest`、原 STL 文件名、私人路径及未授权字体；许可证清单随构建输出。目录被 gitignore 排除不代表构建会自动排除。

检查 steps 中仅 STEP / STP 可追踪，其他文件均被忽略；dist 使用模板白名单，不含 SLDPRT 或其他非 STEP 原文件。检查项目 / 初始模板 GPL-3.0-only 声明与正式 LICENSE，第三方通知保留，输出 JSON / 许可说明与真实模板来源一致。正式发布前复核对应源交付方式，不能仅凭 LICENSE 存在宣称全面合规。

## 6. 报告格式

每个验证记录包含：日期、提交 / 应用版本、模板版本、依赖组合、OS、浏览器版本、硬件、输入 JSON、期望值、实际值、耗时、输出工具版本、结果及剩余风险。

基准测量区分首次 WASM 下载 / 初始化与已加载后的计算，真实记录峰值资源；未完成时不能写“满足性能要求”。发布前整理 PRD A01–A16 的证据列表。
